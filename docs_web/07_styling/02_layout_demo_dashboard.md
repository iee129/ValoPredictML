# 02. 시연 대시보드 레이아웃 (한 화면)

예측 페이지는 **스크롤 없이 1280×800(노트북/빔프로젝터)에 다 들어오는 대시보드**로 짠다. 입력·인사이트·결과가 한 화면에서 동시에 보여야 평가자가 흐름을 즉시 파악한다.

---

## 1. `/predict` — 3구역 그리드

```
┌───────────────────────────────────────────────────────────────────────────┐
│  ValoPredictML   [맵 ▼ Ascent]  [기준연도 ▼ 2026]        모델 AUC 0.76 ·PASS │  ← 상단 바
├──────────────────────────────────┬────────────────────────────────────────┤
│  좌: 라인업 입력 (편집)           │  우: 실시간 인사이트                    │
│                                   │                                        │
│  ▸ 팀 A (레드)                    │  요원-맵 적합도 범례  ✓적합 △보통 ✗비추  │
│   1 [선수▾][요원▾ Jett ✓]         │  ┌──────────────┐ ┌──────────────┐     │
│   2 [선수▾][요원▾ Sova ✓]         │  │ 메타 매칭률  │ │ 구성 결함     │     │
│   3 ...                           │  │   팀A 80%    │ │ 팀A: 없음 ✅  │     │
│  ▸ 팀 B (시안)                    │  │   팀B 63%    │ │ 팀B: 전략가0⚠│     │
│   1 [선수▾][요원▾ Reyna ✓]        │  └──────────────┘ └──────────────┘     │
│   ...                             │                                        │
│        [ 승률 예측하기 ]          │                                        │
├──────────────────────────────────┴────────────────────────────────────────┤
│  하: 예측 결과 (예측 후 이 자리에 인플레이스 표시)                          │
│  ┌────────────┐  팀 A ▰▰▰▰▱ 62%   신뢰도 HIGH   │ 역할 레이더 │ 근거 카드 │ │
│  │ 팀 A 우세  │  팀 B ▰▰▱▱▱ 38%                  │  (A vs B)   │ · 문장1   │ │
│  │   62%      │                                  │             │ · 문장2   │ │
│  └────────────┘                                  └─────────────┴───────────┘ │
└───────────────────────────────────────────────────────────────────────────┘
```

CSS Grid 개념:
```css
.predict-page { display: grid; grid-template-columns: 1.15fr 1fr; gap: 1rem; }
.result-strip { grid-column: 1 / -1; }            /* 결과는 하단 풀폭 */
```

- **좌(입력)**: 맵/연도는 상단 바, 팀 A/B 5슬롯, 예측 버튼. 슬롯의 요원 옆에 적합도 배지.
- **우(인사이트, 예측 전부터 갱신)**: 적합도 범례 + 메타 매칭률 + 구성 결함. 입력만으로 즉시 표시.
- **하(결과, 예측 후)**: 승자 카드 + 승률 게이지 2개 + 신뢰도 + 역할 레이더 + 근거 카드. 한 줄(strip)에 압축.

## 2. 표시 타이밍 (재확인)

| 시점 | 채워지는 영역 |
|------|----------------|
| 맵 선택 | 우 상단 적합도 배지(요원 셀렉트/슬롯) — `GET /agent-map-fit` |
| 슬롯 5개 완성 | 우 메타 매칭률 %(`POST /comp-match`) + 구성 결함(프론트 룰) |
| 예측 클릭 | 하 결과 strip 전체 — `POST /predict`(`explanations`·`balance` 포함) |

상세 → [../06_insights/00_overview.md](../06_insights/00_overview.md) §3.

## 3. `/replay` — 좌:경기선택 / 우:대조 결과

```
┌──────────────────────────────────────────────────────────────┐
│  경기 선택 [▼ 2024-05-01 Ascent T1 vs GenG]                   │
├────────────────────────────┬─────────────────────────────────┤
│  예측 승자  T1 (62%)        │  실제 승자  T1     [ 적중 ✅ ]   │
│  팀 게이지 / 역할 레이더    │  근거 카드                       │
└────────────────────────────┴─────────────────────────────────┘
```
`hit=true`면 그린 "적중 ✅", false면 레드 "불일치 ✗". 콜드스타트 없어 시연 도입부에 안정적.

---

## 4. `/model` — 신뢰성 요약 (도입부 화면)

상단 4개 메트릭 카드(피처 125 · Test AUC · 정확도 · 검증 PASS) + 전역 피처 중요도 바. 시연을 "이 모델은 믿을 만하다"로 시작.

```
[ 125 피처 ] [ AUC 0.76 ] [ ACC 0.70 ] [ 검증 PASS ✅ ]
전역 피처 중요도 ▰▰▰▰▰▰ (상위 12)
```

---

## 5. 반응형·시연 환경

| 폭 | 동작 |
|----|------|
| ≥ 1200px (시연 기본) | 좌우 2열 + 하단 결과 strip (스크롤 없음) |
| 768–1199px | 1열 스택(입력→인사이트→결과) |
| 데모 권장 | 브라우저 전체화면(F11), 100% 줌, 1280×800↑ |

> 빔프로젝터에서 작게 보일 수 있으니 핵심 숫자(승률 %)는 `clamp(2.5rem, 5vw, 4rem)`로 크게.
