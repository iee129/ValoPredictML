# 베이스라인 모델 (랜덤 holdout)

분할축 **랜덤 holdout** × 모델축 **베이스라인**. 전체 기간의 경기를 무작위 80/20으로 나눠 평가한, 가장 단순한 구성의 모델이다. 본 프로젝트의 유일한 베이스라인이며, 심화 모델(시간순 holdout)의 비교 기준점 역할을 한다.

출처: 산출물 발표자료(PDF) 기준 베이스라인 보고값.

## 1. 모델 정의

로지스틱 회귀(LR)와 결정트리(DT)를 soft voting(가중치 0.50 / 0.50)으로 묶은 베이스라인을, `match_key` 단위 무작위 80/20 holdout으로 평가한 구성이다. 421개 피처를 사용한다.

| 항목 | 값 |
|---|---|
| 알고리즘 | LR + DT soft voting (0.50 / 0.50) |
| 분할 | 랜덤 Train 80% / Test 20% |
| 피처 수 | 421 |

## 2. 데이터 분할

- **방식**: `match_key`(경기) 단위 무작위 80/20 분할. 같은 경기에서 나온 여러 맵 행은 train·test 중 한쪽에만 들어간다.
- **튜닝**: train 내부에서 GroupKFold(group=`match_key`)로 하이퍼파라미터를 탐색한 뒤, train 전체로 최종 적합하고 test로 1회 평가한다.
- **소스**: 같은 경기·같은 해 통계는 입력에서 제외하고, 선수 prior는 이전 연도까지만 집계한다.

## 3. 피처 구성 (421)

베이스라인 피처는 **선수 슬롯 피처 400 + 컨텍스트 피처 21**로 구성된다.

| 그룹 | 세부 | 개수 |
|---|---|---:|
| 슬롯 피처 | 10명 × (PRIOR 8 + 요원 원-핫 27 + 역할 원-핫 5) = 10 × 40 | 400 |
| 컨텍스트 | 맵 원-핫 12 + 합동(synergy) 3 + 역할 조합 6 | 21 |
| **합계** | | **421** |

- **슬롯 피처**: 양 팀 10개 선수 슬롯 각각에 이전-연도 prior 8개, 선택 요원 원-핫 27개, 역할 원-핫 5개를 둔다.
- **컨텍스트 피처**: 경기 맵 원-핫 12개, 팀 합동(synergy) 3개, 역할 조합 6개.

## 4. 성능 지표

| 모델 | ROC-AUC | Accuracy | F1 |
|---|--------:|---------:|---:|
| LR | 0.6000 | 0.5821 | 0.6216 |
| DT | 0.5556 | 0.5483 | 0.5860 |
| **앙상블 (soft voting)** | **0.5943** | **0.5667** | **0.6072** |

- 다수 클래스(majority) 기준선 대비 앙상블 정확도는 **+0.0649** 향상이다.
- LR과 DT를 soft voting으로 결합한 앙상블이 두 단일 모델 사이의 균형점을 잡는다.

## 5. 의미 해석

랜덤 holdout은 전 기간에서 무작위로 떼어낸 경기를 맞히는 정도를 본다. train과 test가 같은 시기·소스를 공유하므로, 이전 시즌까지 쌓인 선수·조합 강도가 같은 분포의 test 경기에 비교적 직접 작용한다.

- 선형(LR)과 얕은 트리(DT) 조합이라 표현력이 제한적이며, 비선형 상호작용 학습은 심화 모델(RF+XGB+LGBM)이 담당한다.
- 베이스라인은 majority 대비 +0.0649의 의미 있는 향상을 보이지만, 같은 기간 분포에서의 단순 holdout이라는 점에서 심화 모델의 시간순 holdout(과거→미래 일반화)과는 평가 질문이 다르다.

## 6. 심화 모델과의 위치

| 모델 | 분할 | 피처 | Test AUC |
|---|---|---:|---:|
| 베이스라인 (LR+DT) | 랜덤 80/20 | 421 | 0.5943 |
| 심화 (RF+XGB+LGBM) | 시간순 (train 2020–2025 / test 2026) | 179 | 0.7010 |

두 모델은 분할 축(랜덤 vs 시간순)과 모델 축(LR+DT vs 트리 앙상블)이 모두 다르다. 교차 정리는 [05_cross_model_comparison.md](./05_cross_model_comparison.md)를 본다.
