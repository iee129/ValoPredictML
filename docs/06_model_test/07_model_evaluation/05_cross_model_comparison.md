# 4모델 교차 비교

네 모델은 같은 Kaggle 소스 데이터와 같은 피처 계약 계열(베이스라인 178 / 심화 125)을 공유한다. 차이는
두 축뿐이다 — **분할 축**(랜덤 holdout / 시간순 holdout)과 **모델 축**(베이스라인 / 심화). 이 문서는 두 축이
지표에 만드는 차이를 수치로 정리한다. 각 모델의 단독 분석은 [01](./01_random_baseline.md)~[04](./04_chrono_advanced.md)를 본다.

## 지표 매트릭스

| | 베이스라인 (178) | 심화 (125) |
|---|---|---|
| **랜덤 holdout** | ① Test AUC 0.6587 / Acc 0.6290 / F1 0.7231 | ② Test AUC 0.7570 / Acc 0.6958 / F1 0.7649 |
| **시간순 holdout** | ③ Test AUC 0.6124 / Acc 0.5795 / F1 0.6226 | ④ Test AUC 0.6182 / Acc 0.5885 / F1 0.6539 |

## 분할 축 — 같은 모델, 랜덤 vs 시간순

| 모델 계열 | 랜덤 Test AUC | 시간순 Test AUC | 차이 |
|-----------|--------------:|----------------:|-----:|
| 베이스라인 (①→③) | 0.6587 | 0.6124 | −0.0464 |
| 심화 (②→④) | 0.7570 | 0.6182 | −0.1388 |

같은 모델을 랜덤 분할에서 시간순 분할로 바꿀 때 Test AUC가 달라진다. 베이스라인은 −0.0464, 심화는 −0.1388로,
두 축 사이의 차이는 심화 쪽에서 더 크다.

## 모델 축 — 같은 분할, 베이스라인 vs 심화

| 분할 | 베이스라인 Test AUC | 심화 Test AUC | 차이 |
|------|--------------------:|--------------:|-----:|
| 랜덤 (①→②) | 0.6587 | 0.7570 | +0.0982 |
| 시간순 (③→④) | 0.6124 | 0.6182 | +0.0058 |

같은 분할 안에서 베이스라인을 심화로 바꿀 때의 Test AUC 차이는 랜덤 분할에서 +0.0982, 시간순 분할에서 +0.0058이다.

## train–test AUC 차이 (심화 앙상블)

| 분할 | Train AUC | Test AUC | 차이 |
|------|----------:|---------:|-----:|
| 랜덤 (②) | 0.9550 | 0.7570 | 0.198 |
| 시간순 (④) | 0.9617 | 0.6182 | 0.344 |

심화 앙상블의 train AUC는 두 분할에서 비슷하게 높지만(0.955 / 0.962), test와의 차이는 랜덤 0.198, 시간순 0.344이다.

## 분포 차이 근거 (시간순 분할)

시간순 holdout(③④)의 train(2021–2023)과 test(2024–2026)는 다음 점에서 분포가 다르다. 랜덤 holdout(①②)에는
이런 분리가 없다(전 기간이 train·test에 섞임).

| 항목 | train (2021–2023) | test (2024–2026) |
|------|-------------------|-------------------|
| 라벨 평균 | 0.5802 | 0.5220 |
| 주요 소스 | qualidea·vct·challengers | challengers·piyush2025·vct (train에 없던 piyush 등장) |

또한 train 내부 CV AUC의 표준편차는 랜덤 베이스라인(①) 0.0016, 시간순 베이스라인(③) 0.0103으로, 시간순
구성에서 폴드 간 편차가 더 크다.

## 정리

- 네 모델은 동일 데이터·피처 계약을 공유하므로, 위 차이들은 **분할 축과 모델 축의 효과**로 읽을 수 있다.
- 랜덤 holdout과 시간순 holdout은 서로 다른 경기를 평가한다 — 전자는 전 기간에서 무작위로 뺀 경기, 후자는
  학습 이후 기간(2024–2026)의 경기다. 그래서 두 수치는 같은 잣대의 우열이 아니라 서로 다른 상황에서 잰 값이다.
- 분할별·모델별 수치 차이의 배경(랜덤 분할과 historical prior의 상호작용 등)에 대한 원인 분석은
  [`../../05_data_learning/03_advanced_models/02_advanced_metric_analysis.md`](../../05_data_learning/03_advanced_models/02_advanced_metric_analysis.md)에 정리돼 있다.
