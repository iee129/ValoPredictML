# 2모델 비교

본 프로젝트는 베이스라인 1개와 심화 1개, 총 2개 모델을 비교한다. 두 모델은 **분할 방식**과 **알고리즘**이 모두 다르므로, 단일 잣대의 우열이 아니라 서로 다른 평가 상황에서 잰 값으로 읽어야 한다. 각 모델의 단독 분석은 [01](./01_random_baseline.md)·[04](./04_chrono_advanced.md)를 본다.

## 지표 요약

| 모델 | 분할 | 피처 | 알고리즘 | Test AUC | Test Acc | Test F1 |
|---|---|---:|---|---:|---:|---:|
| 베이스라인 | 랜덤 80/20 | 421 | LR+DT (0.50/0.50) | 0.5943 | 0.5667 | 0.6072 |
| 심화 | 시간순 (train 2020–2025 / test 2026) | 179 | RF+XGB+LGBM (2.0:3.0:0.1) | 0.7010 | 0.6454 | 0.6478 |

## 분할 차이가 핵심

| 모델 | 분할 | train/test 분포 | 답하는 질문 |
|---|---|---|---|
| 베이스라인 | 랜덤 80/20 (`match_key` 단위) | 같은 시기·소스를 train·test가 공유 | 같은 기간 분포 안에서 보류한 경기를 맞히는 정도 |
| 심화 | 시간순 (연도 블록) | train(2020–2025)이 test(2026)보다 모두 과거 | 과거로 학습해 이후 시즌을 맞히는 정도 |

- 베이스라인의 **랜덤 80/20**은 전 기간을 무작위로 뒤섞으므로 train·test가 같은 분포를 공유한다. 평가가 비교적 쉬운 구성이다.
- 심화의 **시간순 holdout**은 학습 이후 시즌(2026)을 평가하므로 분포가 이동한 더 어려운 구성이다.
- 두 분할이 평가하는 경기 집합이 다르기 때문에, 0.5943(베이스, 랜덤)과 0.7010(심화, 시간순)을 직접 우열로 비교하면 오해를 부른다.

## 모델 축 — LR+DT vs 트리 앙상블

| 항목 | 베이스라인 | 심화 |
|---|---|---|
| 알고리즘 | LR + DT soft voting | RF + XGBoost + LightGBM soft voting |
| 가중치 | 0.50 / 0.50 | 2.0 : 3.0 : 0.1 |
| 피처 | 421 (슬롯 400 + 컨텍스트 21) | 179 |
| 상호작용 학습 | 제한적(선형 + 얕은 트리) | 트리 분기로 비선형 상호작용 학습 |
| 튜닝 | GroupKFold 내부 탐색 | Optuna 미사용(고정 하이퍼파라미터) |
| 중요도 | — | `feature_importances_`/휴리스틱(진짜 SHAP 아님) |

## 심화 개별 모델 (시간순 Test)

| 모델 | Test ROC-AUC |
|---|---:|
| RF | 0.6965 |
| XGBoost | 0.7007 |
| LightGBM | 0.7015 |
| **앙상블** | **0.7010** |

세 트리 모델의 Test AUC가 0.6965~0.7015로 근접하며, soft voting 앙상블이 0.7010으로 수렴한다. validation verdict는 `신뢰 가능`이다.

## 정리

- 베이스라인(랜덤 80/20, 421피처, 0.5943)은 같은 기간 분포의 단순 holdout으로, majority 대비 +0.0649의 향상을 보이는 비교 기준점이다.
- 심화(시간순, 179피처, 0.7010)는 과거→미래 일반화를 점검하는 대표 모델로, 앱·웹·발표에 서빙된다.
- 두 수치는 분할·모델 축이 모두 다르므로 같은 잣대의 우열이 아니다. 분할별 수치 차이의 배경은 [`../../05_data_learning/03_advanced_models/02_advanced_metric_analysis.md`](../../05_data_learning/03_advanced_models/02_advanced_metric_analysis.md)에 정리돼 있다.
