# 02. 데이터 갭 분석

## 1. 갭 분석 개요

80% 정확도를 과적합 없이 달성하기 위해 **현재 상태 vs 필요 상태**를 정량적으로 분석한다.

---

## 2. 볼륨 갭 (Volume Gap)

### 2.1 이론적 최소 샘플 수

```
XGBoost + LightGBM 앙상블 (15개 피처):
  경험칙: 피처 수 × 1,000 이상
  최소:   15,000 샘플
  권장:   30,000 샘플
  
피처 30개로 확장 시:
  최소:   30,000 샘플
  권장:   60,000+ 샘플
```

### 2.2 현재 vs 목표

```
                  현재        단기 목표      장기 목표
                  ──────────  ─────────────  ─────────────
총 경기 수:        ~7,000      ≥ 30,000       ≥ 100,000
학습용 샘플:       ~4,900      ≥ 21,000       ≥ 70,000
피처 수:           15          20             30+
예상 정확도:       ~67-72%     ~75-78%        ~80-84%
```

### 2.3 소스별 기여 계획

| 소스 | 현재 | 추가 가능 | 합계 |
|------|------|----------|------|
| Kaggle VCT 2021-2023 | 2,000 | 0 (이미 전부) | 2,000 |
| Kaggle VCT 2024 | 0 | ~1,000 | 1,000 |
| Riot VCT S3 (2021-2024) | 0 | **~180,000+** | 180,000+ |
| HenrikDev API | 0 | ~20,000 | 20,000 |
| Kaggle 랭크 매치 데이터셋들 | 0 | ~50,000+ | 50,000+ |
| VLR.gg 스크래핑 | 0 | ~5,000 | 5,000 |
| **합계** | **2,000** | **~256,000+** | **~258,000** |

## 3. 피처 갭 (Feature Gap)

### 3.1 현재 15개 피처의 한계

현재 피처는 오직 **팀 구성 정보**만 캡처:
- 역할군 카운트 (구체적 요원 정보 손실)
- 맵 이름 (맵-역할군 상호작용 포착 불가)

**손실되는 정보:**
```
❌ 개별 요원 정보 (Jett vs Reyna는 같은 Duelist로 처리)
❌ 팀 시너지 조합 정보 (Sova + Jett 조합이 특히 강한 사실 무시)
❌ 맵별 최적 구성 (Breeze에서 Viper가 필수인 사실 미반영)
❌ 플레이어 스킬 레벨 (프로 vs 다이아 vs 브론즈 동일 취급)
❌ 패치 버전 (2021년 메타 = 2024년 메타로 취급)
```

### 3.2 추가 필요 피처 카테고리

| 카테고리 | 피처 예시 | 예상 성능 향상 |
|---------|---------|------------|
| 개별 요원 원-핫 | `has_jett_teamA` (27종 × 2팀) | +3~5%p |
| 맵별 요원 픽률 | `map_duelist_winrate` | +2~3%p |
| 조합 시너지 점수 | `combo_score_teamA` | +2~4%p |
| 패치 버전 | `patch_version_encoded` | +1~2%p |
| 플레이어 티어 | `avg_rank_teamA` | +3~5%p |
| 팀 폼 | `team_recent_winrate` | +2~4%p |

> **총 예상 향상:** 피처 확장만으로 +5~10%p 정확도 향상 가능

### 3.3 피처 우선순위 매트릭스

```
우선순위 = 성능 향상 기대 × 구현 난이도 역수

1순위 (쉬움 + 효과 큼):
  - 맵별 요원 픽률 통계 (정적 데이터로 계산 가능)
  - 전략가 보유 여부 이진 피처 (이미 있음, 확장)
  - 역할군 조합 유효성 점수

2순위 (중간 난이도 + 효과 큼):
  - 개별 요원 원-핫 인코딩 (27 × 2 = 54개 피처 추가)
  - 패치 버전 인코딩

3순위 (어려움 + 효과 큼, 데이터 필요):
  - 플레이어 평균 랭크 (HenrikDev API 필요)
  - 팀 최근 N경기 승률 (히스토리 데이터 필요)
```

## 4. 다양성 갭 (Diversity Gap)

### 4.1 현재 데이터 분포 편향

```
프로 경기 (VCT) 특징:
  - Controller 보유율: ~95% (일반 유저 65%)
  - Initiator 2인 조합: ~80% (일반 유저 40%)
  - 특정 요원 집중: Viper, Sova, Omen, Jett가 75% 픽 점유

문제: 모델이 학습하는 "이기는 조합"이 프로 메타에 편향됨
      일반 유저가 사용하는 다양한 조합에서 예측 정확도 저하 가능
```

### 4.2 필요한 데이터 다양성

| 데이터 유형 | 현재 비율 | 목표 비율 |
|------------|---------|---------|
| 프로 경기 (VCT) | 100% | 20% |
| 하이 랭크 (이머탈+) | 0% | 30% |
| 미드 랭크 (플레~다이아) | 0% | 35% |
| 로우 랭크 (~골드) | 0% | 15% |

## 5. 시간적 갭 (Temporal Gap)

### 5.1 메타 변화 타임라인

```
2021 ─── 2022 ─── 2023 ─── 2024 ──→ (현재)
  |         |         |         |
 VCT       VCT       VCT    VCT +
2021      2022      2023    신규 요원
 ✅        ✅        ✅       ❌
 
현재 데이터: 2021-2023 커버
누락된 기간: 2024 전체 (Clove, Tejo, Waylay 출시 이후)
```

### 5.2 신규 요원 데이터 부재

| 요원 | 역할군 | 출시 | 데이터 존재 여부 |
|------|--------|------|--------------|
| Clove | Controller | 2024 | ❌ 없음 |
| Tejo | Initiator | 2024 | ❌ 없음 |
| Waylay | Duelist | 2024 | ❌ 없음 |

> **영향:** 2024년 출시 요원이 포함된 팀 조합 예측이 부정확할 수 있음.  
> 신규 요원은 현재 역할군 카운트에는 반영되나, 해당 요원의 승률 특성은 학습되지 않음.

## 6. 갭 해결 우선순위

```
1단계 (즉시 실행 가능, 고효과):
  [★★★] Riot VCT S3 Hackathon 데이터 다운로드 → +180,000 경기
  [★★★] Kaggle 추가 데이터셋 수집 → +50,000+ 경기

2단계 (중간 노력, 중간 효과):
  [★★] 피처 30+ 확장 구현 → +5~10%p 정확도
  [★★] HenrikDev API 수집 자동화 → +20,000 경기

3단계 (높은 노력, 추가 개선):
  [★] VLR.gg 스크래핑 구현
  [★] 플레이어 랭크 피처 추가
```
