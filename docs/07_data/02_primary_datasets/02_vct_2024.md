## 2. 컬럼 정의

### detailed_matches_player_stats.csv

**행 단위**: 선수 1명 × 맵 1개.

| 컬럼 | 설명 |
|------|------|
| `match_id` / `event_name` / `match_date` | 경기 식별 정보 |
| `team1` / `team2` | 양 팀 이름 |
| `player_name` / `player_team` / `agent` | 선수·팀·요원 |
| `acs` / `k` / `d` / `a` | 스탯 컬럼 |
| `kast` | KAST% (일부 이벤트 결측 — ⚠️) |
| `adr` / `hs_percent` / `fk` / `fd` | 스탯 컬럼 |
| `map_name` | 맵 이름 |
| `map_winner` | 이 맵의 승팀 — 레이블 소스 (조인 불필요) |

KAST 가용성: ⚠️ 일부 이벤트 결측 — `-1` 플래그로 처리.
