## 5. 2021-2023과의 병합 방법

### 5.1 컬럼 호환성 확인

```python
def check_compatibility(df_2021_2023: pd.DataFrame, df_2024: pd.DataFrame):
    """두 데이터셋의 컬럼 호환성 확인"""
    cols_old = set(df_2021_2023.columns)
    cols_new = set(df_2024.columns)
    
    missing_in_new = cols_old - cols_new
    extra_in_new = cols_new - cols_old
    
    print(f"구버전에 있고 신버전에 없는 컬럼: {missing_in_new}")
    print(f"신버전에만 있는 컬럼: {extra_in_new}")
    
    return len(missing_in_new) == 0 and len(extra_in_new) == 0
```

### 5.2 병합 코드

```python
import pandas as pd
import glob, os

def load_all_kaggle_vct(base_dir: str = "data/raw/kaggle") -> pd.DataFrame:
    """2021-2023 + 2024 Kaggle VCT 데이터 통합 로드"""
    all_dfs = []
    
    year_dirs = {
        "vct_2021_2023": "2021-2023",
        "vct_2024": "2024",
    }
    
    for folder, year_label in year_dirs.items():
        folder_path = os.path.join(base_dir, folder)
        if not os.path.exists(folder_path):
            print(f"[WARN] 없음: {folder_path}")
            continue
        
        csv_files = glob.glob(os.path.join(folder_path, "**/*.csv"), recursive=True)
        for f in csv_files:
            df = pd.read_csv(f)
            df["vct_year"] = year_label
            all_dfs.append(df)
    
    combined = pd.concat(all_dfs, ignore_index=True)
    print(f"[INFO] 전체 VCT: {len(combined)} 행")
    return combined
```

## 6. VCT 2024 메타 특성

VCT 2024에서 주목할 메타 변화:

| 메타 변화 | 설명 | 데이터적 의미 |
|---------|------|------------|
| Clove 등장 | 새로운 Controller 추가 | Controller 조합 다양화 |
| 더블 Controller 증가 | Viper + Clove 조합 등장 | Controller diff 패턴 변화 |
| Sentinel 감소 | 프로 씬에서 Sentinel 1인 또는 0인 증가 | Sentinel 계수 분포 변화 |
| 픽-밴 없음 | VCT에는 픽-밴이 없음 (5명 모두 선택) | 피처 설계에 영향 없음 |
