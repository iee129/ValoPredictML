```python
import shutil, os

# kagglehub 캐시 경로 → 프로젝트 data/raw/ 로 복사
def copy_to_project(kaggle_path: str, dest: str = "data/raw/kaggle/vct_2021_2023"):
    os.makedirs(dest, exist_ok=True)
    for f in os.listdir(kaggle_path):
        src = os.path.join(kaggle_path, f)
        dst = os.path.join(dest, f)
        if os.path.isdir(src):
            shutil.copytree(src, dst, dirs_exist_ok=True)
        else:
            shutil.copy2(src, dst)
    print(f"[INFO] 복사 완료: {dest}")
```

## 5. 데이터 로드 코드

```python
import glob
import pandas as pd
import os

def load_vct_kaggle(base_dir: str = "data/raw/kaggle/vct_2021_2023") -> pd.DataFrame:
    """VCT 2021-2023 Kaggle 데이터셋 전체 로드"""
    csv_files = glob.glob(os.path.join(base_dir, "**/*.csv"), recursive=True)
    
    if not csv_files:
        raise FileNotFoundError(f"CSV 없음: {base_dir}")
    
    dfs = []
    for f in sorted(csv_files):
        try:
            df = pd.read_csv(f, encoding="utf-8")
            # 연도 추출 (파일 경로에서)
            year = os.path.basename(os.path.dirname(f))
            df["year"] = year
            df["source_file"] = os.path.basename(f)
            dfs.append(df)
            print(f"[INFO] 로드: {os.path.basename(f)} ({len(df)} 행)")
        except Exception as e:
            print(f"[WARN] 로드 실패: {f} → {e}")
    
    combined = pd.concat(dfs, ignore_index=True)
    print(f"\n[INFO] 합계: {len(combined)} 행, {len(csv_files)} 파일")
    return combined
```

## 6. 데이터 특성 및 주의사항

### 6.1 알려진 특성

- 행 단위: **플레이어** (1경기 = 10행, 각 팀 5명)
- 모델 학습 전 **경기 단위**로 집계 필요 (`aggregate_to_match_level()`)
- `team_a` / `team_b` 정의가 파일마다 다를 수 있음 (항상 알파벳 순 정렬되지 않음)
- 일부 파일에서 `acs` 컬럼이 `avg_combat_score`로 다를 수 있음 → 컬럼 표준화 필수

### 6.2 데이터 품질 이슈

| 이슈 | 빈도 | 처리 방법 |
|------|------|---------|
| NaN 수치 컬럼 | 드물게 | 0으로 대체 |
| 팀 이름 오타/대소문자 차이 | 가끔 | `.str.strip().str.lower()` 정규화 |
| 존재하지 않는 맵 이름 | 드물게 | VALID_MAPS 검증 후 제거 |
| 중복 행 (동일 match_id + player) | 가끔 | `drop_duplicates` |
