---

## 1. 기본 정보

| 항목 | 내용 |
|------|------|
| Kaggle ID | `ryanluong1/valorant-champion-tour-2021-2023-data` |
| 용량 | 1.2GB |
| 기간 | 2021~2026 VCT 전 대회 |

| 소스 가중치 | 1.0 |

## 2. 주요 파일 구조

```
vct_2021_2023/
├── vct_2021/
│   ├── players_stats/
│   │   └── *.csv   ← 선수-맵 단위 스탯
│   └── maps_scores/
│       └── *.csv   ← 팀 점수 + 공수 기록
├── vct_2022/ (동일 구조)
├── vct_2023/ (동일 구조)
└── vct_2024/ ~ vct_2026/ (동일 구조)
```

파서가 `vct_2021/`~`vct_2026/` 재귀 탐색. `all_ids/` 폴더는 건너뜀.

---

## 3. 컬럼 정의

### players_stats/*.csv

| 컬럼 | 설명 |
|------|------|
| `Tournament` | 대회명 |
| `Stage` | 대회 단계 (`Group Stage`, `Playoffs`, `Grand Final`) |
| `Match Type` | 경기 포맷 (`BO1` / `BO3` / `BO5`) |
| `Player` | 선수 이름 |
| `Teams` | 선수 소속 팀 |
| `Agents` | 이 맵에서 선택한 요원 |
| `Rounds Played` | 총 라운드 수 |
| `Rating` | VLR.gg 종합 기여도 점수 |
| `ACS` | Average Combat Score |
| `KD` | Kill / Death 비율 |
| `KAST` | Kill/Assist/Survived/Traded 라운드 비율(%) |
| `ADR` | Average Damage per Round |
| `FK` / `FD` | First Kill / First Death 횟수 |
| `HS%` | 헤드샷 비율(%) |
| `Clutch%` | 클러치 성공률(%) |

KAST 가용성: ✅

### maps_scores/*.csv

| 컬럼 | 설명 |
|------|------|
| `Match Name` / `Map` | 조인 키 (players_stats와 조인) |
| `Team A` / `Team B` | 양 팀 이름 |
| `Score A` / `Score B` | 라운드 승리 수 — 승패 레이블 소스 |
| `Attacker Score` | 공격(T) 사이드 라운드 승리 수 — `atk_side_advantage` 집계 소스 |
| `Defender Score` | 수비(CT) 사이드 라운드 승리 수 |

조인 키: `Match Name` + `Map`.

---

## 4. 파이프라인 역할

- ryanluong 파서 메인 소스
- `maps_scores.csv`의 `Attacker Score`/`Defender Score`로 `atk_side_advantage` 집계
- 승패 레이블: `Score A > Score B` → `label = 1`
