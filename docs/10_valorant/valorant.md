## 1. 발로란트란?

**발로란트(Valorant)**는 2020년 Riot Games(리그 오브 레전드 개발사)가 출시한 **5대5 전술 팀 슈팅 게임**입니다.

쉽게 말하면:

```
축구처럼 팀이 서로 맞붙는 게임인데,
총을 들고 싸우며 "스파이크(폭탄)를 심거나 해제"하는 것이 목표입니다.
```

- **전 세계 월간 이용자 수:** Riot 공식 월간 활성 사용자 수는 공개 확인이 어렵다. 제3자 추정치는 2026년 4월 기준 약 2,990만 명 수준으로 제시되지만, 공식 지표가 아니므로 배경 규모 참고용으로만 사용한다.
- **e스포츠 규모:** VCT(Valorant Champions Tour) — Riot 공식 일정상 2026년에도 Kickoff, Masters, Stage, Champions로 이어지는 글로벌 서킷이며, 누적 상금 규모는 외부 집계 기준 수천만 달러 수준이다.
- **무료 플레이:** PC(Windows)와 지원 지역의 PS5/Xbox Series X|S에서 무료 플레이 가능
- **국내 인기:** 한국에서도 FPS(1인칭 슈팅) 장르 중 가장 인기 있는 게임 중 하나

## 2. 게임 방식 — 어떻게 진행되는가?

### 2.1 기본 구조

```
┌─────────────────────────────────────────────────────────────┐
│  한 판 = 최대 25 라운드                                       │
│  먼저 13 라운드를 이기는 팀이 승리                             │
│                                                             │
│  팀 A (공격팀)   VS   팀 B (수비팀)                           │
│  5명                     5명                                │
│                                                             │
│  하프타임 기준으로 공격/수비 진영이 교체됨                      │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 한 라운드의 흐름

```
[구매 단계 - 30초]
→ 돈으로 총기, 방어구, 스킬 구매

[전투 단계 - 100초]
→ 공격팀: 스파이크(폭탄)를 지정 구역(A사이트 / B사이트)에 심으려 함
→ 수비팀: 심지 못하게 막거나, 심었으면 해제

[라운드 종료]
→ 공격팀 승리 조건: 적 5명 모두 처치 또는 스파이크 폭발
→ 수비팀 승리 조건: 적 5명 모두 처치 또는 스파이크 해제 또는 시간 초과
```

### 2.3 맵(Map)이란?

맵은 전투가 벌어지는 **전장(경기장)**입니다. 각 맵마다 구조와 전략이 완전히 다릅니다.

| 맵 이름 | 특징 | 유리한 역할군 |
|---|---|---|
| Corrode | 프랑스 성곽 도시/염광 시설 배경, 전통적 3라인 구조 | 정보 수집+지역 장악 |
| Ascent | 중앙 미드가 중요, 균형잡힌 구조 | 척후대(정보 수집) |
| Bind | 일방통행 텔레포터 있음, 독특한 구조 | 전략가(연막 제어) |
| Haven | 사이트 3개 (A/B/C), 방어 범위가 넓음 | 감시자(지역 잠금) |
| Split | 수직 구조, 밀집 전투 | 타격대(개인 교전) |
| Icebox | 넓고 열린 구조 | 저격수 요원 유리 |
| Breeze | 가장 넓은 맵, 장거리 교전 | 원거리 요원 |
| Pearl | 수중 도시 테마, 균형잡힌 구조 | 전략가+척후대 조합 |
| Lotus | 회전문 메커니즘, 3사이트 | 정보 수집 중요 |
| Sunset | 도시 배경, 좁은 골목 | 근거리 강한 요원 |
| Abyss | 가장자리 추락 구역, 특수 지형 | 기동성 요원 |
| Fracture | H자 구조, 양방향 공격 가능 | 기습 가능한 요원 |

경쟁전/데스매치 로테이션은 패치마다 바뀐다. 예를 들어 Patch 12.08에서는 Ascent가 경쟁전과 데스매치 큐에 들어오고 Bind가 빠진다고 공지되었다.

## 3. 요원(Agent)이란?

발로란트의 가장 독특한 특징은 **각 플레이어가 특수 능력을 가진 캐릭터(요원)를 선택**한다는 점입니다.

```
일반 FPS:       총 + 기술만
발로란트:       총 + 기술 + 고유 스킬(4개)
```

### 3.1 요원의 스킬 구성

각 요원은 4가지 스킬을 보유합니다:

| 슬롯 | 이름 | 설명 |
|---|---|---|
| C | 기본 능력 1 | 가장 저렴하거나 무료 |
| Q | 기본 능력 2 | 라운드당 구매 |
| E | 고유 능력 | 자동 충전 (쿨타임) |
| X | **궁극기** | 킬/포인트 모아서 발동 |

### 3.2 요원 예시

**Jett (젯) — 타격대**
```
직업: 한국 출신 바람 조종사
특기: 빠른 기동성으로 적 처치 후 탈출
궁극기: 날카로운 칼날을 무한정 던지기
역할: 팀의 1번 프래거 (가장 많이 죽이는 역할)
```

**Sova (소바) — 척후대**
```
직업: 러시아 출신 궁수·정찰병
특기: 드론과 정찰 화살로 적 위치 파악
궁극기: 벽을 관통하는 충격파 발사
역할: 팀에게 적 위치 정보 제공
```

**Viper (바이퍼) — 전략가**
```
직업: 독성 화학 전문가
특기: 독가스와 산성 장벽으로 구역 통제
궁극기: 넓은 독 연기로 시야 차단
역할: 진입로 차단, 사이트 점령
```

**Killjoy (킬조이) — 감시자**
```
직업: 독일 출신 천재 기술자
특기: 터렛, 경보기 등 기계 장치 설치
궁극기: 범위 내 적 장비 무력화
역할: 지역 방어, 스파이크 지킴
```

## 4. 역할군(Role)이란? — 이 프로젝트의 핵심 개념

발로란트의 모든 요원은 **4가지 역할군** 중 하나에 속합니다.

```
┌──────────────────────────────────────────────────────────────┐
│                   4대 역할군                                   │
│                                                              │
│  🔴 타격대(Duelist)    🔵 척후대(Initiator)                   │
│     "죽여라"              "알아내라"                           │
│                                                              │
│  🟢 전략가(Controller) 🟡 감시자(Sentinel)                    │
│     "막아라"              "지켜라"                             │
└──────────────────────────────────────────────────────────────┘
```

### 4.1 역할군 상세 설명

#### 🔴 타격대 (Duelist)
- **한 줄 요약:** 팀의 앞에서 돌진하여 적을 처치하는 공격 선봉대
- **특징:** 개인 능력이 뛰어나고, 적을 1:1로 상대할 때 유리
- **약점:** 팀워크보다 개인기에 의존 → 혼자선 강하지만 혼자만 있으면 약함
- **요원 예시:** Jett(젯), Reyna(레이나), Phoenix(피닉스), Neon(네온), ISO(아이소)
- **팀에 필요한 수:** 보통 **1~2명**

#### 🔵 척후대 (Initiator)
- **한 줄 요약:** 적 위치 정보를 팀에게 알려주고, 진입 환경을 만들어주는 지원대
- **특징:** 정찰 드론, 섬광 등으로 팀 진입을 돕는 "길 열어주는 역할"
- **약점:** 혼자 싸우기 불리, 팀이 함께 움직여야 능력 발휘
- **요원 예시:** Sova(소바), Breach(브리치), Skye(스카이), Fade(페이드), Gekko(게코)
- **팀에 필요한 수:** 보통 **1~2명**

#### 🟢 전략가 (Controller)
- **한 줄 요약:** 연막과 장벽으로 적의 시야를 차단하고 구역을 통제하는 전술가
- **특징:** 연막(smoke)을 피워 적이 못 보게 하고, 팀이 안전하게 이동하도록 지원
- **약점:** 개인 전투력이 낮음, 스킬 관리를 잘못하면 팀 전체가 흔들림
- **요원 예시:** Viper(바이퍼), Brimstone(브림스톤), Astra(아스트라), Omen(오멘), Harbor(하버)
- **팀에 필요한 수:** **무조건 1명 이상 필수** (없으면 사이트 진입 불가에 가까움)

#### 🟡 감시자 (Sentinel)
- **한 줄 요약:** 측면과 후방을 지키며 팀의 안전망을 구축하는 방어 전문가
- **특징:** 적이 예상치 못한 방향에서 오는 것을 탐지·차단
- **약점:** 방어적인 플레이에 특화되어 있어 공격 라운드에서는 기여도가 낮을 수 있음
- **요원 예시:** Killjoy(킬조이), Cypher(사이퍼), Sage(세이지), Chamber(챔버), Deadlock(데드락)
- **팀에 필요한 수:** 보통 **1~2명**

### 4.2 역할군이 왜 중요한가?

```
나쁜 라인업 예시:
  타격대 5명 = 전부 혼자 돌진 → 아무도 정보 없이 죽음
  전략가 0명 = 연막 없음 → 사이트 진입 시 상대방이 다 봄

좋은 라인업 예시:
  타격대 1 + 척후대 2 + 전략가 1 + 감시자 1
  → 정보 수집 → 연막 설치 → 선봉 돌진 → 측면 방어
  → 유기적인 전략 실행 가능
```

**결론: 역할군의 균형이 곧 팀의 강함을 결정합니다.**

## 5. 왜 라인업이 승패에 영향을 미치는가?

### 5.1 체스와 비슷한 개념

| 체스 | 발로란트 |
|---|---|
| 폰(기본 병사) | 타격대 |
| 나이트(기동성) | 척후대 |
| 비숍(원거리) | 전략가 |
| 룩(수비) | 감시자 |
| 퀸(만능) | 혼성형 요원 |

체스에서 폰만 8개를 쓰는 사람이 없듯, 발로란트도 **역할의 균형**이 전략의 기본입니다.

### 5.2 분석 가설 예시

아래 수치는 현재 저장소의 실측 평가 결과가 아니라, 역할군 균형이 모델 피처가 될 수 있음을 설명하기 위한 예시다. 실제 조합별 승률은 전처리 산출물과 `reports/model/` 평가 리포트로 대체해야 한다.

| 조합 유형 | 예시 승률 |
|---|---|
| 전략가 1명 이상 포함 | ~58% |
| 전략가 0명 | ~38% |
| 척후대 + 전략가 + 감시자 균형 조합 | ~61% |
| 타격대 3명 이상 | ~44% |

> 이런 역할군/조합 패턴이 **ValoPredictML이 검증하려는 핵심 피처 후보**입니다.

### 5.3 맵별 조합 차이는 향후 확장 후보

같은 팀이라도 맵에 따라 유불리가 달라질 수 있다. 현재 Streamlit 필수 입력은 아니지만 원천 데이터 메타데이터로 보존하고, 표본 수가 충분하면 확장 피처로 검토한다.

```
Breeze (넓은 맵): 원거리 교전 → 저격 요원, 정찰 요원 유리
Split (좁은 맵):  근거리 전투 → 타격대, 근접 감시자 유리
Haven (3사이트):  3방향 동시 방어 필요 → 정보 수집 요원 필수
```

## 6. e스포츠(프로 경기)와 일반 유저의 차이

이 프로젝트의 데이터는 두 계층에서 옵니다:

```
┌─────────────────────────────────────────────────────────────┐
│  프로 경기 (VCT)                                              │
│  - 공식 VCT와 주요 프로/준프로 팀들의 경기                      │
│  - 메타(유행하는 조합)를 선도                                  │
│  - 데이터: Kaggle VCT 2021~2026, Challengers, VLR.gg 미러       │
│  - 특징: 전략적으로 최적화된 조합 사용                          │
│                                                             │
│  일반 랭크 경기 (일반 유저)                                    │
│  - 취미로 즐기는 수백만 명의 경기                               │
│  - 프로 메타를 따라가거나 직접 실험                             │
│  - 데이터: 일반/랭크 Kaggle 후보, HenrikDev API 선택 수집        │
│  - 특징: 다양하고 예측 불가능한 조합                            │
└─────────────────────────────────────────────────────────────┘
```

**왜 현재는 프로/준프로 경기 데이터만 사용하는가?**
프로 경기 데이터는 Kaggle에 이미 정리된 CSV 파일로 존재해서 API 없이 바로 사용할 수 있다. 반면 일반 유저 데이터는 HenrikDev API나 Riot API를 통해 실시간 수집이 필요한데, 이 프로젝트는 외부 API 미사용 방침을 적용했다.

**프로 데이터만 쓸 때의 한계**
프로 경기에서 강한 조합이 일반 유저 경기에서도 똑같이 강하지 않을 수 있다. 예를 들어 프로 팀은 Initiator의 정찰 스킬을 완벽히 활용하지만, 일반 유저 경기에서는 그 스킬을 제대로 쓰지 못하는 경우가 많다. 이 한계는 발표에서 명시적으로 언급한다.

두 데이터를 합쳐서 학습함으로써 **프로 수준의 전략 지식 + 일반 유저 패턴**을 모두 반영합니다.

## 7. ValoPredictML — 이 프로젝트가 해결하는 문제

### 7.1 현실에서 발생하는 문제

```
[픽창(요원 선택 화면)]
매 게임 시작 전 1분 30초 안에 요원을 골라야 함.

이 시간 동안 팀원들은:
  ❌ "전략가 없는데요?"라고 말해도 이미 늦음
  ❌ 어떤 조합이 이 맵에서 유리한지 알 수 없음
  ❌ 상대 라인업을 보고 대응 픽을 할 판단 시간이 부족함
```

### 7.1.1 왜 단순 통계 조회가 아닌 ML 모델을 쓰는가?

"Viper가 Ascent에서 승률 몇 %인가"는 단순히 과거 데이터를 집계해서 알 수 있다. 그러나 "Viper + Jett + Sova + Killjoy + Reyna 조합이 팀 B의 Omen + Breach + Chamber + Raze + Fade 조합을 상대로 이 맵에서 이길 확률은?"처럼 변수가 10개 이상 동시에 조합된 상황은 데이터에 그 정확한 조합의 경기가 없다. ML 모델은 수천 개의 경기에서 패턴을 학습하여 **본 적 없는 조합도 추정**할 수 있다.

### 7.2 ValoPredictML이 제공하는 답

```
[사용자 행동]
1. Streamlit 로컬 분석 도구 실행
2. 우리 팀/상대 팀 선수 5명 선택
3. 우리 팀/상대 팀 요원 5명 선택
4. 필요한 선수 정보 보정

[시스템이 제공하는 정보]
→ "이 조합의 예상 승률: 67.3% (중간 신뢰도)"
→ "팀 A 역할군: 타격대 1 / 척후대 2 / 전략가 1 / 감시자 1"
→ "승패에 가장 큰 영향을 미치는 요소: 전략가 수 차이"
```

### 7.3 누구에게 도움이 되는가?

| 사용자 유형 | 활용 방법 |
|---|---|
| **입문자** | "이 맵에서 전략가는 꼭 뽑아야 하는구나" — 기본 전략 학습 |
| **일반 유저** | 픽창에서 라인업 짜기 전 빠른 확인 |
| **팀/파티** | 스쿼드 전략 수립 시 데이터 기반 의사결정 |
| **e스포츠 팬** | 대회 전 팀별 조합 분석 및 예측 |
| **게임 분석가** | 메타 트렌드 연구, 역할군 시너지 분석 |
| **개발자** | ML + 게임 데이터 분석 사례 연구 |

## 8. 발로란트 메타(Meta)란?

**메타(Meta)**는 "현재 가장 강한 전략"을 의미합니다.

```
예시: 특정 시즌 메타 가정
"전략가 2명 + 척후대 2명 + 타격대 1명" 조합이
상위권 프로 경기에서 자주 관측되는 조합이라고 가정

→ 이 패턴이 데이터에서 높은 승률로 나타남
→ 모델이 이 패턴을 학습
→ 사용자가 비슷한 조합을 선택하면 높은 승률 예측
```

메타는 매 시즌 패치(업데이트)에 따라 변합니다. 이 때문에:
- **모델 재학습** 기능이 필요합니다
- 새로운 요원 출시 시 **Unknown 처리** 로직이 필요합니다

## 9. 용어 사전

| 용어 | 설명 |
|---|---|
| **스파이크(Spike)** | 게임 내 폭탄. 공격팀이 설치, 수비팀이 해제 |
| **사이트(Site)** | 스파이크를 설치할 수 있는 구역 (A사이트, B사이트 등) |
| **픽창** | 게임 시작 전 요원을 선택하는 화면 (픽 페이즈) |
| **프래그(Frag)** | 적을 처치하는 것 |
| **에이스(Ace)** | 혼자 상대 팀 5명을 모두 처치하는 것 |
| **클러치(Clutch)** | 불리한 상황(1vs다)에서 역전 승리 |
| **스무크(Smoke)** | 전략가가 설치하는 연막, 시야 차단 |
| **플래시(Flash)** | 섬광탄, 일시적으로 시야 차단 |
| **얼트(Ult)** | 궁극기(Ultimate) 줄임말 |
| **메타(Meta)** | 현 시점에서 가장 강한/유행하는 전략 |
| **패치(Patch)** | 게임 업데이트 (밸런스 조정) |
| **VCT** | Valorant Champions Tour — 공식 e스포츠 대회 |
| **인게임(in-game)** | 현재 게임이 진행 중인 상태 |
| **픽률(Pick Rate)** | 전체 게임에서 특정 요원이 선택되는 비율 |
| **승률(Win Rate)** | 해당 요원/조합을 사용했을 때 이기는 비율 |
