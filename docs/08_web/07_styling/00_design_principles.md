# 00. 디자인 원칙 — 시연·평가용 고가독성

이 UI의 목적은 **교수님 앞 라이브 시연 + 평가**다. 미적 화려함보다 **"한 화면에서 모든 게 즉시 읽히는 것"**이 최우선이다. 발로란트 정체성(택티컬·각진·레드)은 가독성을 해치지 않는 선에서 액센트로만 쓴다.

---

## 1. 4대 원칙

| 원칙 | 의미 | 구현 규칙 |
|------|------|-----------|
| **At a glance** | 핵심 결론이 0.5초 안에 보임 | 승자·승률을 가장 큰 타이포로, 색으로 즉시 구분 |
| **Single screen** | 예측 흐름이 스크롤 없이 1280×800에 다 들어옴 | 입력=좌, 인사이트=우, 결과=하단 인플레이스 |
| **High readability** | 한국어 본문이 또렷, 대비 충분 | 본문 Pretendard, 대비 ≥ 4.5:1, 최소 14px |
| **Explain, don't decorate** | 모든 시각요소가 정보를 전달 | 배지·색·바는 의미와 1:1, 장식용 모션 금지 |

---

## 2. 평가자가 1분 안에 봐야 할 것 (우선순위)

```
1) 예측 승자 + 승률 %        ← 가장 큼, 색 강조
2) 신뢰도 (HIGH/MED/LOW)     ← 배지
3) 왜 그런가 (자연어 2~4문장) ← 근거 카드
4) 입력 구성의 품질
   - 요원-맵 적합도 ✓/△/✗
   - 메타 매칭률 %
   - 구성 결함 경고
5) 모델 신뢰성 (AUC·검증 신뢰 가능) ← /model 페이지 (도입부)
```

UI 레이아웃은 이 우선순위를 시각적 크기·위치로 그대로 반영한다([02_layout_demo_dashboard.md](02_layout_demo_dashboard.md)).

---

## 3. 색의 의미 (고정 규약)

색을 장식이 아니라 **신호**로만 쓴다. 같은 의미엔 항상 같은 색.

| 색 | 의미 | 사용처 |
|----|------|--------|
| 레드 `#ff4655` | 브랜드·팀 A·주 CTA·위험 | 팀 A, 예측 버튼, high 경고 |
| 시안 `#29c5e0` | 팀 B (구분색) | 팀 B 게이지/헤더/슬롯 |
| 그린 `#30d08c` | 긍정·적합·적중 | ✓ 적합, replay 적중 |
| 앰버 `#ffd166` | 주의·보통 | △ 보통, medium 경고 |
| 뮤트 `#9ba3b3` | 비활성·보조 | △ 중립, 보조 텍스트 |

> 팀 A=레드 / 팀 B=시안은 **전 화면 불변**. 게이지·슬롯·역할 레이더·근거 모두 이 두 색으로 좌우를 가른다.

---

## 4. 금지 사항 (가독성 보호)

- 본문에 장식용 디스플레이 폰트 사용 금지(숫자·제목만 허용)
- 저대비 회색 위 회색, 레드 위 시안 텍스트 금지
- 자동 캐러셀·불필요한 트랜지션·패럴럭스 금지(시연 중 산만)
- 한 화면에 3개 초과 강조색 동시 사용 금지
- 정보 없는 빈 카드/플레이스홀더 노출 금지(없으면 숨김)
