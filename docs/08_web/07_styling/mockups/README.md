## 핵심 개정 (구버전 대비)
- **예측 탭 통합**: 구 `/predict` 페이지를 home에 합침 → **단일 예측 페이지**. nav = 홈/다시보기/모델(3개), `/predict` 라우트 폐지.
- **model 페이지 전면 재설계**: 설명형 ML 리포트(세로 확장) — 성능평가 + 일반화 진단 + EDA + 학습·검증 방법. **"누수검증 PASS / 신뢰 가능" 판정 배지 제거**(설명형 시각화로 대체).
- **새 비주얼 시스템**(아래) 적용.

## 디자인 시스템 (현행)
- **글로우 전면 금지**. 방사형 발광·blur 헤일로 없음.
- **각진 택티컬**: 챔퍼(우상단 컷, clip-path) + HUD 코너틱은 히어로/결과 카드·CTA에만 절제 적용.
- **`//` 슬래시 라벨**: 영문 대문자 eyebrow(MAP·MATCHUP·MODEL 등), 슬래시만 레드.
- **신호색 고정**: 팀 A/T1 레드 `#ff4655`, 팀 B/상대 시안 `#29c5e0`, 적합/적중 그린 `#30d08c`, 주의/보통 앰버 `#ffd166`.
- **역할색 코딩**(정체성, 신호색과 구분): 듀얼리스트 `#ff7d4d` · 이니시에이터 `#5b8cff` · 컨트롤러 `#b388ff` · 센티넬 `#ffd166`.
- **요원 displayIcon 아바타**: 로스터·경기 조합에 실제 요원 얼굴(팀색 링). 이니셜 텍스트 폐지.
- **맵 스플래시 배경 + 글래스 카드**: 페이지 배경에 어둡게 깐 맵 이미지, 핵심 히어로 카드는 반투명(~80%)으로 배경이 비침. 배너는 좌측만 어둡게 하는 단일 그라데이션(맵 연속). *전면 배경 이미지를 쓸 때 배너에 별도 로컬 스플래시를 또 깔지 말 것 — 이중 이미지로 제목부 경계가 생김.*
- **방향성 음영 그라데이션**(글로우 아님): 막대 게이지는 좌(밝)→우(짙), 패널은 위(밝)→아래(짙).
- **웜 본** `#ece8e1`: 큰 중립 디스플레이(맵명·승자·스코어·워드마크). 신호색은 유지.
- **타이포**: 디스플레이 Bebas Neue(영문·숫자), 한국어 본문 Pretendard. 한글 라벨 자간 0.

## 파일 ↔ 화면 ↔ Figma 노드 (현행)
| 화면 | 워크플로 | Figma node | 비고 |
|------|---------|-----------|------|
| `/` 홈(통합 예측) | 맵 배너(스플래시+셀렉터) + 로스터 입력(요원 아이콘·역할색·적합) + 결과 히어로(거대 %·모멘텀·요원 풀아트) + 피처 중요도·역할레이더·조합점검 + 승부근거 | `60:2` (캔버스 y=0) | 구 predict 흡수 |
| `/replay` 다시보기 | 경기 사이드레일 + 적중 판정·실제승자 + 경기 조합(요원 아이콘) + 모델예측·피처 중요도·예측vs실제 | `32:2` | |
| `/model` 모델 리포트 | 성능평가(AUC·ROC·평가방식·데이터셋 도넛 + 모델비교·피처중요도·혼동행렬+지표) + 일반화 진단(과적합·CV) + EDA(타겟·맵별 승패 샘플 수·KD↔승률·연도메타) + 학습검증방법 | `34:2` (세로 1184) | PASS 배지 없음 |

> 구 predict 프레임(28:2)은 home에 통합되며 삭제됨. 노드 ID는 재생성 시 바뀌므로 라이브 Figma 파일이 기준.

## 차별점 (Streamlit/일반 통계 사이트 대비)
- 피처 중요도(A/B 발산형 막대) + 자연어 승부 근거
- 요원-맵 적합도 배지 ✓/△/✗(색+기호+텍스트 3중 인코딩) + 구성 결함 경고
- 역할 구성 4축 레이더(A vs B) · 요원 displayIcon 로스터/조합
- 다시보기: 예측 vs 실제 적중 대조
- 모델: 무작위 vs 시간순 정직 병기 + ROC·혼동행렬·CV·EDA 설명형 리포트
